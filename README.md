# Weather CLI

## About

This project is a Python-based command-line application that fetches real-time weather information for a city using the Open-Meteo API.

## Features

- Fetches weather information for a city.
- Retrieves the city's latitude, longitude, and country.
- Displays temperature, humidity, wind speed, and weather conditions.
- Handles invalid city names and network errors.

## Built With

- Python
- Requests library
- Open-Meteo Geocoding API
- Open-Meteo Weather API

## How to Run

1. Install Python.
2. Install the required dependency:

   `python -m pip install requests`

3. Run the application:

   `python main.py`
